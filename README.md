# AI-Powered Traffic Management System

## Project Overview
Traffic congestion is a major challenge in modern urban areas. Traditional traffic signal systems operate using fixed timing, which does not adapt to real-time traffic conditions.

This project presents an **AI-Powered Traffic Management System** that uses vehicle detection and intelligent decision-making to dynamically control traffic signals. The system analyzes traffic density from multiple directions and optimizes signal timing to reduce congestion and improve traffic flow.

The solution is designed for **smart city traffic management**, enabling efficient and adaptive signal control.

---

## Problem Statement
Conventional traffic signals use fixed-time control mechanisms that cannot respond to real-time traffic conditions. This results in:

- Long waiting times
- Traffic congestion
- Increased fuel consumption
- Higher air pollution
- Inefficient road utilization

An intelligent system is required to monitor traffic density and dynamically adjust signal timing.

---

## Objectives
- Detect vehicles from road cameras
- Analyze traffic density in different directions
- Dynamically adjust traffic signal timing
- Reduce waiting time and congestion
- Improve overall traffic efficiency

---

## System Architecture

The system consists of the following components:

1. Camera / Traffic Input
2. Vehicle Detection Model
3. Traffic Density Analyzer
4. Traffic Signal Controller
5. Monitoring Dashboard

The AI model detects vehicles and calculates traffic density for each road direction (North, South, East, West). Based on the detected traffic load, the system adjusts signal timing dynamically.

## Dashboard Metrics

The system dashboard displays:

- Average Wait Time
- Traffic Throughput
- Model Inference Time
- Detection Confidence
- Cycle Time

It also provides manual traffic simulation where users can increase or decrease vehicles in each direction.

---

## How It Works

1. Traffic images are captured from cameras.
2. The AI model detects vehicles in each lane.
3. Traffic density is calculated.
4. The signal timing is adjusted dynamically.
5. The dashboard updates the traffic status in real time.
